面料染整厂管理系统 —— 使用说明
====================================

一、安装
  1. 把「面料染整厂管理系统.exe」拷到工厂电脑上，建议放在
     D:\面料管理\  这样的固定文件夹里（不要放桌面或U盘）。
  2. 双击运行。第一次启动会自动在同一个文件夹里生成：
        data\      —— 数据库（你所有的数据都在这里）
        backups\   —— 自动备份
  3. 电脑上不需要装 Python 或任何别的东西。

  ！重要：以后不要单独拷 exe，要拷就把整个文件夹一起拷（data 是命根子）。


二、第一次使用，先做三件事
  1. 点右上角「设置」→ 公司信息，填工厂名称、地址、电话、开户行账号。
     这些会打印在送货单和对账单的抬头上。
  2. 点「基础资料」→ 面料档案，把常做的面料录进去（也可以不录，
     录进仓单时直接打面料名，系统会自动建档）。
     工艺已经预置了：染色、定型、磨毛、防水、预缩、印花，可以自己加。
  3. 点「基础资料」→ 价格表，按 客户 + 面料 + 工艺 录加工费单价。
     面料留空 = 这个客户这道工艺的通用价。
     以后发货时单价会自动带出来，也可以手改。


三、日常操作流程
  【客户来料】
    主窗口 → 新增客户（只有客户名是必填的）
    双击客户 → 进仓 Tab → 新增进仓单
      填缸号、面料、颜色、卷数、米数。一张进仓单可以录多个缸号。
      需要逐卷记米数的，点「码单」，可以直接从 Excel 复制一列米数粘进去。

  【发货】
    客户窗口 → 发货 Tab → 新增发货单
      在缸号格里输入缸号（或点「选缸号」从库存里挑），
      面料、颜色、剩余卷数米数会自动带出来；
      填工艺后单价自动带出，填卷数米数后金额自动算。
      「填剩余」按钮 = 把剩余的卷数米数一次填满（发完尾货用）。
      一张送货单可以发多个缸号。
    保存后点「打印送货单」，会打开浏览器打印，一式两联（存根联 + 客户联）。

  【收款】
    客户窗口 → 收款 Tab → 新增收款，填日期、金额、方式（现金/转账/承兑/抵扣）。

  【月底对账】
    客户窗口 → 对账单 Tab → 选「上月」或自定义日期区间
      期初欠款 + 本期应收 − 本期已收 = 期末应收
      点「打印对账单」给客户，或「导出 Excel」。


四、几个要注意的地方
  1. 缸号在同一个客户里不能重复，重复了系统会拦住你。
     不同客户可以有相同缸号，互不影响。

  2. 「是否发完」看的是卷数，不是米数。
     染整必然有缩率（进仓 1000 米，发货可能只有 970 米），
     所以剩余米数几乎永远不会是 0。剩余卷数归零 = 这缸货发完了。

  3. 缸号发完后，系统会算出缩率%。
     缩率超过 8%（可在设置里改），或者缩率是负数（发货比进仓还多），
     这一行会标黄提醒你 —— 通常是数字录错了，回头查一下。

  4. 零头不想再发了（比如剩 1 卷报损作废），
     在进仓 Tab 选中这一行，点「标记已结清」，它就不再占着库存了。

  5. 单据金额是保存时锁定的。
     以后你在价格表里改单价，不会影响以前已经开好的单子。

  6. 发货卷数超过剩余，系统会警告，但允许你确认后强行保存
     （现实中确实会有补数的情况）。


五、备份
  程序每次启动和退出都会自动备份，保留最近 30 份（可在设置里改）。
  设置 → 备份，可以手动备份、查看备份列表、从某个备份恢复。

  如果另一台电脑误用了「本机数据」，先让对方退出软件，再把对方程序目录中
  data\fabric_erp.db 复制一份到服务器电脑。在服务器上打开：
    设置 → 备份 → 合并另一台电脑的数据
  软件会先预览新增、重复、单号改编和冲突；确认后自动备份服务器，只把缺少的
  记录整批合入。不要用对方的数据库直接覆盖服务器数据库。

  客户端使用的是服务器数据，客户端上的「立即备份/恢复」会被禁用；数据库备份
  和合并只能在管理数据的服务器电脑操作。

  强烈建议：每隔一段时间把整个 backups 文件夹拷到U盘或网盘。
  电脑硬盘坏了，本机备份也一起没了。


六、出问题了怎么办
  程序报错时会弹窗显示错误信息，把弹窗截图发给我。
  数据没丢的话，用 设置 → 备份 → 从选中备份恢复，可以退回到之前的状态。


七、版本与更新
  1. 软件版本号显示在窗口标题栏，以及「设置」页面的底部。
     每次发新版本，exe 文件名会带上版本号（如 面料复合加工管理系统-v2.0.0.exe），
     方便分清是哪一版。

  2. 会计那台（「连别人的电脑」的客户端）：
     · 每次打开软件时会自动检查服务器上有没有新版本，有的话会问你要不要更新。
     · 也可以随时在「设置 → 多人共用/手机」里点「检查更新」手动检查。
     · 更新会自动下载、替换程序并重启，数据不受影响。

  3. 你自己这台（管数据的服务器）：
     · 拿到新 exe 后，放到原程序同一个文件夹里，双击新的那个即可，
       数据还是同一个 data\ 文件夹里的账。
     · 以后就把带版本号的旧 exe 留着归档，别混在一起分不清。
